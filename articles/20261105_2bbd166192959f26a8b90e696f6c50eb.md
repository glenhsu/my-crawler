: 藍營酸沈伯洋「無餡」都更！張景森提10大步驟：根本不用懷疑
: 自由
: 針對台北市長蔣萬安競選團隊及藍營議員質疑，民進黨台北市長候選人沈伯洋提出的「無
: 限都更」，是天馬行空的「無餡都更」，前行政院政務委員張景森今（3日）直言，無限
: 都更根本不用懷疑可不可行，國防部過去早就完成近7萬戶國軍老舊眷村改建安置；他也
: 根據眷村改建與跨區土地整合的實務經驗，提出「無限都更10大實施步驟」。
: 張景森今天以「沈伯洋提出的『無限都更』可不可行？根本不用懷疑！」為題在臉書發文
: 表示，眷村改建本質上就是由政府主導的大規模跨區遷建與老屋更新：跳脫單一基地各自
: 整合、找建商的泥淖，由政府將分散各地的老舊聚落納入統籌計畫，落實「先建後遷、跨
: 區整合、土地循環」。這套機制安置了近7萬戶家庭，同時釋出大量土地活化，早已證明
: 政府主導跨基地住宅更新，在實務上完全行得通。
: 張景森直言，過去20年來仰賴容積獎勵、放任地主與建商個別博弈的「小政府政策」，已
: 被證實效率遠遠跟不上老屋老化的速度。他因此提出「無限都更」的改良版「10大具體實
: 施步驟」供沈伯洋、蔣萬安與中央政府參考：
: 第一步：建立全市都市更新與住宅交換平台。政府應該把需要更新的老舊社區，納入全市
: 統一的更新平台，不必讓每個基地各自找建商、談條件、籌資金。市政府負責盤點更新需
: 求、居民意願，以及台北市住宅供給及可開發土地，統籌安排更新時程與住宅交換。
: 第二步：先找地興建「遷建住宅」，不是中繼住宅。政府先尋找適當基地，透過公開招商
: 、民間合作或購買成屋，取得第一批遷建住宅。張景森強調，這是「遷建住宅」，不是「
: 中繼住宅」。
: 中繼住宅是暫時搬出去，等原地重建完成再搬回來。他認為沒有必要把居民綁在原來的地
: 址上，也不相信大部分台北人一定要堅持跟他原來的鄰居住一起；原來住在同一棟公寓的
: 人，未來不一定還要繼續當鄰居。有人希望靠近工作地點，有人希望靠近子女，有人希望
: 換大房子，也有人希望換小房子。政府應該提供不同地點、坪數及價格的住宅，讓居民自
: 由選擇。搬進新家，就是永久遷居，完成安置，老屋換新屋，不必再搬第二次。
: 第三步：以屋換屋、以權換屋，多退少補。居民拿出原有的房屋與土地權利，交換政府提
: 供的新住宅。雙方都經過公平估價，依照價值差額多退少補。例如，原有房地價值1500萬
: 元，選擇1200萬元的新住宅，就可以拿回300萬元；選擇1800萬元的新住宅，就要補足300
: 萬元。這不是政府送房子，而是人民以自己的財產交換新的住宅。
: 第四步：同意的先換，不同意的繼續住。假設某個社區有100戶，其中75戶願意換屋，25
: 戶不願意。那就讓75戶先搬進新住宅，其他25戶繼續住在原地。不必等所有住戶同意，就
: 可以開始改善居民的居住條件，也不必急著拆除舊屋。完成交換後，政府取得75戶舊房屋
: 及相應的土地權利，開始成為舊社區的重要地主。這裡的75戶是自願交換的比例，不代表
: 已經達到都市更新的法定同意門檻。交換住宅與拆除重建是兩個不同階段，前者可以先做
: ，後者仍須依法辦理。
: 第五步：取得的舊屋，先作為社會住宅與公共服務空間。政府取得舊屋以後，不必立即拆
: 除。只要建築安全、消防及使用條件許可，可以適當整修，作為社會住宅、青年出租住宅
: 、老人日間照顧、社區托育或其他公共服務空間。這等於把部分原本要投入興建社會住宅
: 的資金，轉為透過換屋取得既有住宅，再加以整修利用。舊屋在等待整合期間，還可以產
: 生租金收入，減少政府的資金負擔。
: 第六步：政府逐步成為主要地主，再推動整體更新。隨著越來越多居民換屋，政府取得的
: 房地權利逐步增加。原來100戶的社區，可能先有75戶換屋，後來增加到85戶、90戶。政
: 府已經成為重要地主，就可以主動招商、規劃整體更新。剩下的住戶可以依法參與權利變
: 換，取得更新後住宅或其他法定補償。當更新計畫符合都市更新法定條件，完成必要的同
: 意、審議、權利變換及拆遷程序後，就可以依法進行拆除重建。
: 第七步：政府以容積參與更新，不再白白送出容積獎勵。這是我整套制度最重要的改革主
: 張。土地是人民的，房子是人民的，但是新增容積是政府透過都市計畫創造的公共價值。
: 過去政府主要把容積獎勵提供給地主及建商，希望他們願意更新。我主張改成：政府以容
: 積參與更新，而不只是以容積獎勵更新。
: 政府除了以地主身分參與更新後的權利分配以外，應該透過修法，建立新增容積的公共利
: 益回收制度。新增容積所創造的主要公共利益，應該回到都市更新循環基金，支持下一輪
: 遷建住宅與跨區更新。當然，容積並不是政府現行法律下可以任意出售的財產。這套公共
: 回饋制度必須透過法律明確授權，也必須保障原地主權益，並考慮交通、公共設施及都市
: 環境承載能力。
: 第八步：引進建商、銀行及壽險資金。政府不必自己蓋所有房子，也不必獨自負擔全部資
: 金。建商可以負責興建遷建住宅，也可以參加開發更新基地，銀行可以提供融資，壽險公
: 司則可以在符合法令的條件下，投資長期出租住宅、社會住宅或提供長期資金。政府負責
: 統籌規劃、建立交易制度、保障居民權益及回收公共利益。民間負責資金、建築、管理與
: 經營。
: 第九步：更新完成後，處分部分住宅，回收資金。舊基地完成重建後，政府依照原有房地
: 權利、資金投入及依法取得的公共回饋，分配更新後的住宅與其他資產。一部分出售，回
: 收初期資金；一部分保留作為社會住宅或出租住宅；另一部分可以作為下一輪交換住宅的
: 資源。這樣就不必每完成一批更新，都重新投入同樣規模的政府預算。
: 第十步：建立都市更新循環基金，持續推動下一輪更新。政府把出售住宅的收入、出租收
: 益及依法取得的公共容積回饋，納入都市更新循環基金。再用這些資源取得下一批遷建住
: 宅，讓更多老舊社區加入交換。整套制度形成一個循環：興建遷建住宅 → 居民以屋換屋
: →政府取得舊屋→舊屋暫時活化→整合舊基地→更新重建→回收資金→興建下一批遷建住
: 宅。這不能保證每一個更新案都能賺錢，但是透過跨基地整合、容積公共回饋及資產循環
: ，可以減少對政府持續補貼的依賴。
: 張景森說，都市更新最需要更新的是制度本身。國軍眷村改建已經證明，政府可以統籌分
: 散各地的老舊住宅，先建後遷，跨區安置，再逐步處理原有土地。今天大家有更成熟的金
: 融市場、更大的民間資金，也有更完整的都市計畫與住宅政策工具，應該有機會把這套制
: 度做得更好。希望沈伯洋的「無限都更」能夠引起真正的政策討論，也希望蔣萬安以及中
: 央政府都能認真研究。
: 張景森強調，都市更新不應該是哪一個政治人物的專利，更不應該只是選舉政見。先建後
: 遷，以屋換屋；跨區整合，容積入股；公私合作，資金循環。這就是他所構想的「無限都
